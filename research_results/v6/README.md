# V6 research bundle

Artefactos compactos de auditoría del experimento V6. El histórico de mercado, las decisiones
diarias y las curvas completas permanecen fuera de Git; este directorio conserva métricas,
selección de políticas, diagnósticos de modelos y fechas máximas de etiquetas utilizadas.

La evaluación 2023–agosto de 2026 es retrospectiva y no constituye un holdout independiente.
