# Estado del MVP

El MVP está implementado y satisface los criterios de aceptación definidos en la especificación
experimental.

- Datos históricos de QQQ descargables y preparación reproducible de variables.
- Tres agentes cuantitativos, tres roles LLM y coordinación jerárquica determinista.
- Personalidades configurables y perfil conservador congelado para el experimento principal.
- Backtesting walk-forward, costes de transacción y tres baselines.
- Disciplina temporal comprobada mediante auditoría de entrenamiento y paquetes fechados.
- Explicabilidad SHAP, casos LIME, justificaciones LLM y referencias de evidencia validadas.
- Validación 2020-2022 y test final 2023-2024 ejecutados sin recalibración posterior.
- Caché, control presupuestario, proveedor intercambiable y fallback local para sentimiento.
- Dashboard con comparación de estrategias y trazabilidad de decisiones.
- Suite automatizada de pruebas y comprobación estática del código.

Las mejoras posteriores quedan fuera del MVP: fuente de noticias históricas con marcas temporales
verificables, evaluación de otros perfiles, análisis estadístico de sensibilidad y nuevo ciclo
experimental con un test no utilizado. No debe reutilizarse 2023-2024 para ajustar esta versión.
