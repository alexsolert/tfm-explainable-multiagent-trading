# Piloto LLM sobre la decisión del 30 de diciembre de 2022

## Alcance

Se ejecutó un único caso del periodo de validación con el snapshot
`gpt-5.4-mini-2026-03-17`. El paquete de contexto contenía exclusivamente variables de mercado y
señales cuantitativas disponibles el 30 de diciembre de 2022. No se suministraron noticias y no se
consultó el periodo final 2023-2024.

## Resultado

El agente de contexto de mercado produjo una señal de `-0,18` con confianza `0,72`, sustentada en
la debilidad de tendencia, MACD y momentum. El agente de sentimiento devolvió una señal neutral
con confianza `0,12`, al no disponer de evidencia textual. El validador estratégico produjo una
señal de `-0,18` con confianza `0,63` y consideró que la acción cuantitativa `HOLD` era coherente
con una postura conservadora. Tras combinar los seis agentes, el coordinador obtuvo una puntuación
de `-0,0598` y mantuvo `HOLD`, sin veto de riesgo.

## Coste y ajustes operativos

El límite inicial de 300 tokens con esfuerzo de razonamiento `low` se consumió antes de generar la
salida estructurada. Se cambió el esfuerzo a `none`, admitido por el modelo, y se elevó el máximo a
600 tokens para completar el validador. Estos cambios corrigieron el formato de ejecución y no se
basaron en el resultado financiero. Las tres respuestas válidas almacenadas en caché representan
un coste estimado de `0,004663 USD`. Incluyendo dos respuestas truncadas, el coste total estimado
del proceso fue `0,008377 USD`. Una repetición posterior recuperó las tres respuestas desde caché,
con coste incremental nulo.
